# Product Design Principles

This file defines how to think about the product experience. Keep implementation rules in the other docs.

## Product Direction

Design My Plot should feel like a focused workspace for planning, comparing, and refining plot or property-related decisions. The UI should feel practical, structured, and trustworthy.

Do not optimize for a generic SaaS landing page. Optimize for a user who wants to complete a concrete task with confidence.

## Design Values

- Clarity over visual novelty
- Workflow over decoration
- Real data over filler content
- Useful hierarchy over symmetric sections
- Simple components over artificial component systems
- Maintainable UI over screenshot polish

## Product Tone

The interface should feel:

- Calm
- Useful
- Organized
- Direct
- Production-ready

It should not feel:

- Overly playful
- Card-heavy without reason
- Template-generated
- Decorative before functional
- Built only to impress visually

## Decision Rule

Before adding a section, wrapper, card, effect, or component, ask:

```text
What user problem does this solve?
```

If the answer is weak, remove it.
